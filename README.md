## 🌟 Overview

**BUILD MY DREAM** is a production-grade digital platform designed for homeowners, property owners, and families looking to transform their dream home concepts into professionally designed, engineered, and constructed architectural realities.

### Key Highlights
- 🏛️ **Signature 300-Frame Dream-Home Journey**: 60fps HTML5 Canvas scrubber rendering the complete 16-stage evolution from initial vision and excavation to a finished luxury villa at dusk.
- 📐 **Interactive 3D Structural BIM Simulator**: Permanent Three.js WebGL model viewer with orbit controls, layer filtering (`ALL`, `CORE`, `COLUMNS`, `SLABS`), and FEA load stress simulation.
- 🎨 **Luxury Architectural Design System**: Warm architectural white aesthetic (`#FAFAF9` / `#FFFFFF`), high-contrast obsidian typography (`#0F172A`), and champagne gold accents (`#B38E5D`).
- 📋 **Accessible Dream-Home Estimator**: Interactive RFP form with accessible budget brackets (`Below ₹25L`, `₹25L–₹50L`, `₹50L–₹1Cr`, `₹1Cr+`), plot layout dropzone, and celebration confetti.
- 🌐 **11 Full-Featured Multi-Page Routes**: Homepage, About Us, Services, Projects, Project Detail, Technology, Sustainability, Safety & QA, Sectors, Careers, and Contact.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation
```bash
git clone https://github.com/hidayathullahs/engineering-construction-project.git
cd engineering-construction-project
npm install
```

### Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🏗️ Architecture & Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | React 19 + Vite 6 | Lightning-fast component rendering and HMR |
| **Routing** | React Router DOM v7 | 11 multi-page routes with instant transitions |
| **Canvas Engine** | HTML5 2D Canvas + Double Buffering | 60fps frame scrubbing across 300 photorealistic frames |
| **3D Graphics** | Three.js | Interactive 5D BIM structural skeleton & FEA simulation |
| **Animation** | GSAP 3 + ScrollTrigger | Precision timeline scroll triggers |
| **Smooth Scroll** | Lenis | Inertial momentum scrolling |
| **Icons** | Lucide React | Clean, scalable architectural SVG iconography |
