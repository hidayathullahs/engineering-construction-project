# 09. SEO Specification

## Metadata & Search Architecture
- **Title Tags**: Tailored page titles with primary brand keyword: `VERTEX | International Engineering & Infrastructure Group`.
- **Meta Descriptions**: Compelling descriptions highlighting precision engineering, structural integrity, and EPC delivery.
- **Open Graph & Twitter Cards**: Formatted social preview tags with high-contrast architectural imagery.
- **Semantic Structure**: Strict single `<h1>` hierarchy per page with semantic `<main>`, `<section>`, `<header>`, and `<footer>` elements.
