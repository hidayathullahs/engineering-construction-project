# 03. User Flows & Navigation Architecture

## Primary User Journeys

### Journey 1: Commercial Client / RFP Lead
1. Land on Homepage → Cinematic Hero introduces scale and precision.
2. Scroll to Construction Time-Lapse → Interact with 16 stages to witness technical execution rigor.
3. Explore Featured Projects → Filter by Commercial → Select Apex Tower case study.
4. Review Challenge & Solution → Click "Request Project Consultation" → Complete RFP parameters on `/contact`.

### Journey 2: Engineering Candidate / Professional
1. Discover Culture on Homepage Careers preview.
2. Navigate to `/careers` → Review CADRE values and open roles.
3. Click "Apply Now" on targeted position → Fill brief dossier modal → Receive immediate dispatch confirmation.
