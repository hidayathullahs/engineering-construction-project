# 02. Product Requirements Document (PRD)

## Target Audience
- Institutional property developers, government infrastructure authorities, corporate real estate directors, architects, and senior engineering candidates.

## Core Features
1. **Time-Lapse Construction Scrubber**: 300-frame canvas animation synchronized to scroll position with active milestone telemetry HUD.
2. **Interactive 3D BIM Viewer**: Three.js WebGL model with structural layers and FEA stress simulation.
3. **Filterable Project Portfolio**: Instant category filtering, search query input, and deep editorial case study routing.
4. **Interactive Practice Switcher**: 8 core practices with capabilities, machinery, and track record metrics.
5. **Project RFP & Tender Form**: Full client-side validation, project scale estimator, blueprint file upload dropzone simulation, and instant 24-hr guarantee state.
